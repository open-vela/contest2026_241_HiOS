The HiOS implementation is native LVGL code, not the Android Java application.
The original remote segmentation service is not used by HiOS.
No additional dictionary is installed. Per the user's updated instruction,
HiOS reuses its existing input-method phrases, groups Latin words/numbers,
and provides UTF8-safe individual-character splitting and swipe selection.
